# LGEA 한계

## 현재 구현 한계

- 현재 judge는 heuristic rubric 기반이며, 모델 기반 adjudicator가 아닙니다.
- 분석 결과의 신뢰도는 확보된 live 응답 표본 수에 직접적으로 좌우됩니다.
- provider별 요청 형식 차이, rate limit, 네트워크 상태가 live 실행을 제한할 수 있습니다.

## 연구 한계

- 각 surface의 실행 경로와 실패 조건이 달라 결과 비교 시 동일 조건 통제가 필요합니다.
- 모든 surface가 동일한 정도로 live-ready 상태는 아니며, surface별 구현 성숙도 차이가 있습니다.
- 현재 결과는 `RESPONSE_PROMPT` 고정 조건과 category별 질문 세트에 제한됩니다.

## 운영 한계

- 현재 분석은 추론 통계까지 포함하지 않습니다.
- 시각화는 Markdown 표 중심이며, 논문용 그림 자산은 아직 없습니다.
- 수동 검토 샘플링 워크플로는 아직 붙어 있지 않습니다.

## 다음 보완 과제

- heuristic judge를 강화된 evaluator로 대체
- 통계 검정 및 그림 생성 단계 추가
- live run 확대와 사람 검토 샘플링 도입
## 추가 제한점: 통계 우월성 주장

- 현재 comparative analysis 계층은 구현되어 있지만, 파일럿 표본 수는 여전히 작다.
- 따라서 현재 결과만으로 `통계적으로 우월하다`는 강한 결론을 일반화하면 안 된다.
- 다만 동일 분석기를 반복 실행 결과에 적용할 수 있으므로, 표본이 누적되면 동일 형식의 논문 문장으로 확장 가능하다.
