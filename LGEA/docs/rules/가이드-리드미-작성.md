# README 작성 가이드

이 문서는 `idol_agent_LUMI` 저장소와 그 안의 `LGEA` 연구 워크스페이스에서 일관된 README를 작성하기 위한 기준입니다.

대상:
- 저장소 루트 `README.md`
- `LGEA/<subdir>/README.md`

## 공통 작성 원칙

- 문서는 한국어로 작성합니다.
- 첫 문단에서 역할을 1~2문장으로 명확히 설명합니다.
- 실행 가능한 명령어는 `bash` 코드 블록으로 제공합니다.
- 경로/모듈/심볼은 백틱으로 표기합니다.
- 실제 구현과 다른 예정 표현은 최소화합니다.

## 루트 README 기준

루트 `README.md`는 서비스 프로젝트 소개와 실행 방법을 중심으로 작성합니다.

### 권장 섹션

1. 프로젝트 개요
2. 주요 기능
3. 프로젝트 구조
4. 실행 방법
5. 환경 변수
6. 개발 환경

## LGEA 하위 README 기준

LGEA 하위 README는 해당 컴포넌트의 목적과 실행 방법을 중심으로 작성합니다.

### 권장 섹션

1. 개요
2. 목적
3. 입력/출력
4. 주요 파일
5. 실행 방법
6. 산출물 위치

## 체크리스트

- [ ] 첫 문단에서 역할이 명확한가
- [ ] 실행 명령어가 실제 경로와 일치하는가
- [ ] 산출물 위치가 현재 구조와 일치하는가
- [ ] README가 LGEA 현재 phase와 모순되지 않는가
