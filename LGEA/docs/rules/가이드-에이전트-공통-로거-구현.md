# 개요

이 문서는 IDE LLM 에이전트가 새로운 에이전트를 추가할 때 `loguru` 기반 공통 로거를 일관되게 적용하도록 돕기 위한 구현 가이드입니다.
목표는 코드 변경 없이 설정 파일만 수정해 로그 포맷/레벨을 조정할 수 있게 만드는 것입니다.

# 적용 대상

- 신규 에이전트(예: `app/agents/<new_agent>/`)
- 기존 에이전트의 로깅 구조를 설정 파일 기반으로 전환할 때
- 팀 내 공통 로깅 형식이 필요한 경우

# 표준 디렉토리 구조

```plaintext
app/
  agents/
    <agent_name>/
      logger.py
      graph.py
      nodes/
      tools/
config/
  logging/
    <agent_name>.yaml
```

# 구현 원칙

- 로깅 설정은 코드가 아니라 `config/logging/<agent_name>.yaml`에서 관리한다.
- `logger.py`는 다음 2개 함수만 외부에 제공한다.
  - `configure_logger(level: str | None = None)`: 프로세스 시작 시 1회 초기화
  - `get_logger(module: str)`: 모듈 컨텍스트를 바인딩한 로거 반환
- 각 모듈(`graph.py`, `nodes/*`, `tools/*`)은 `get_logger("모듈명")`으로 로거를 생성한다.
- 로그 레벨 기준:
  - `DEBUG`: 내부 처리 단계, skip 분기
  - `INFO`: 시작/완료, 집계 개수
  - `WARNING`: 입력 누락/설정 파일 누락/지원 불가 스키마
  - `ERROR/EXCEPTION`: 예외 발생

# 구현 절차

# 1) 의존성 추가

- `pyproject.toml`에 다음 의존성이 있어야 한다.
  - `loguru`
  - `pyyaml`

# 2) 에이전트별 logger.py 생성

- 경로: `app/agents/<agent_name>/logger.py`
- 요구사항:
  - 환경변수 기반 설정 파일 경로 지원
    - 예: `MY_AGENT_LOG_CONFIG`
  - 설정 파일 미존재/파싱 실패 시 기본값으로 폴백
  - `logger.remove()` 후 sink 1개만 등록(중복 출력 방지)

# 3) YAML 설정 파일 생성

- 경로: `config/logging/<agent_name>.yaml`
- 최소 키:
  - `level`, `backtrace`, `diagnose`, `sink`, `format`

# 4) 그래프/노드/툴에 로거 연결

- 각 파일 상단에서 로거 생성:
  - `logger = get_logger("nodes.parse_ast")` 형태 권장
- 함수 내부 로그 추가:
  - 시작/완료(Info), 분기(Debug), 실패(Warning/Exception)

# 코드 템플릿

# 1) logger.py 최소 템플릿

```python
from __future__ import annotations

import os
import sys
from pathlib import Path
from typing import Any

import yaml
from loguru import logger

_LOGGER_CONFIGURED = False
_PROJECT_ROOT = Path(__file__).resolve().parents[3]
_DEFAULT_CONFIG_PATH = _PROJECT_ROOT / "config/logging/<agent_name>.yaml"
_DEFAULT_LOGGER_CONFIG: dict[str, Any] = {
    "level": "INFO",
    "backtrace": False,
    "diagnose": False,
    "sink": "stderr",
    "format": "{time:YYYY-MM-DD HH:mm:ss.SSS} | {level: <8} | {extra[module]}:{function}:{line} | {message}",
}


def _load_logger_config() -> tuple[dict[str, Any], str]:
    config_path = Path(
        os.getenv("<AGENT_ENV_LOG_CONFIG>", str(_DEFAULT_CONFIG_PATH))
    ).expanduser()
    if not config_path.is_absolute():
        config_path = (_PROJECT_ROOT / config_path).resolve()

    if not config_path.exists():
        return dict(_DEFAULT_LOGGER_CONFIG), f"logging config not found: {config_path}"

    try:
        loaded = yaml.safe_load(config_path.read_text(encoding="utf-8")) or {}
        if not isinstance(loaded, dict):
            raise TypeError("logging config must be a mapping")
    except Exception as exc:
        return dict(_DEFAULT_LOGGER_CONFIG), f"failed to load logging config: {exc}"

    config = dict(_DEFAULT_LOGGER_CONFIG)
    config.update(loaded)
    return config, ""


def configure_logger(level: str | None = None) -> None:
    global _LOGGER_CONFIGURED
    if _LOGGER_CONFIGURED:
        return

    config, warning_message = _load_logger_config()
    if level:
        config["level"] = level

    sink_name = str(config.get("sink", "stderr")).lower()
    sink = sys.stdout if sink_name == "stdout" else sys.stderr

    logger.remove()
    logger.add(
        sink,
        level=str(config["level"]),
        backtrace=bool(config["backtrace"]),
        diagnose=bool(config["diagnose"]),
        format=str(config["format"]),
    )
    _LOGGER_CONFIGURED = True
    if warning_message:
        logger.bind(agent="<agent_name>", module="logger").warning(warning_message)


def get_logger(module: str):
    configure_logger()
    return logger.bind(agent="<agent_name>", module=module)
```

# 2) 모듈 사용 템플릿

```python
from app.agents.<agent_name>.logger import get_logger

logger = get_logger("nodes.example_node")

def example_node(state: dict) -> dict:
    logger.info("example_node 시작")
    try:
        # ... business logic ...
        logger.info("example_node 완료")
        return {"status": "ok"}
    except Exception:
        logger.exception("example_node 실행 실패")
        raise
```


# 운영 시 변경 방법

- 로그 포맷/레벨 변경: `config/logging/<agent_name>.yaml`만 수정
- 코드 변경 없이 반영하려면 프로세스를 재시작한다(시작 시 1회 로드 정책)
- 임시 경로 전환이 필요하면 환경변수로 설정 파일 경로를 변경한다.
  - 예: `REPOSITORY_AGENT_LOG_CONFIG=/abs/path/custom.yaml`

# 검증 체크리스트

- `logger.py`에서 `configure_logger()`가 1회 초기화로 동작한다.
- 설정 파일 누락 시 경고 로그 + 기본값 폴백이 동작한다.
- `graph.py`, `nodes/*`, `tools/*`에서 `get_logger(...)`를 사용한다.
- 로그에 `module:function:line`이 출력된다.
- YAML 수정 시 코드 변경 없이 로그 형식이 바뀐다.
