# AGENTS.md 업데이트 규칙

## 목적

- `AGENTS.md`를 LGEA 연구 워크스페이스의 신뢰 가능한 단일 진입점으로 유지합니다.

## 적용 범위

- `LGEA/docs/rules/AGENTS.md`
- `LGEA/docs/rules/README.md`

## 핵심 원칙

- `AGENTS.md`에는 확정된 실행 규칙만 작성합니다.
- 상세 절차는 `LGEA/docs/rules/*.md`에 둡니다.
- 변경 후에는 `LGEA/docs/rules/README.md` 인덱스와의 연결 상태를 반드시 검증합니다.

## 표준 업데이트 절차

1. 작업 유형을 분류하고 `LGEA/docs/rules/README.md`에서 기준 문서를 확인합니다.
2. 변경 근거 문서를 먼저 확인합니다.
3. `AGENTS.md`를 최소 변경으로 수정합니다.
4. 상세 절차는 개별 문서에 남기고 `AGENTS.md`에는 요약 규칙만 반영합니다.
5. 참조 경로와 용어가 실제 문서와 일치하는지 검증합니다.
6. 인덱스 문서를 갱신합니다.

## 완료 체크리스트

- [ ] `AGENTS.md`가 확정 규칙 중심으로 작성되었는가
- [ ] 상세 절차는 개별 문서로 위임되었는가
- [ ] `LGEA/docs/rules/README.md` 인덱스가 최신 상태인가
