## 20:07:01 | Initial Conversation Summary

사용자는 `docs/LGEA` 기반으로 새로운 연구 프로젝트를 기획 중이며, 기존 `LUMI` 서비스 구조를 유지한 채 연구용 메타 시스템을 별도로 구성할 수 있는지 검토를 요청했다.

주요 합의 사항:
- 연구 목표는 모델별 API 자체의 guardrail 붕괴 특성 비교 실험이다.
- 평가 대상은 LLM 응답층이며 RAG는 제외한다.
- 실험 변수는 모델 목록, 브랜치별 페르소나(`drug`, `bomb`, `adult`), 공격 유형/강도다.
- 브랜치별 페르소나 프롬프트를 현재 브랜치에서 연구 프로세스에 맞게 변환 가능한 형태로 관리한다.
- 최종 결과물은 논문용 상세 리포트다.
- 기존 앱 구조는 유지하고, 연구 전용 자산은 루트 `LGEA/` 아래에서 분리 관리한다.

진행 내역 요약:
