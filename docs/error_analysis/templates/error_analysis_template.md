| 정상 | N | N% | 의도한 대로 정상 동작 |

### 카테고리 분류 기준

- **정상**: 사용자 질문에 적절히 응답, 캐릭터 유지, 응답 시간 적절 (< 3초)
- **오류**: Tool 호출 실패, 할루시네이션, 응답 없음, 시스템 에러
- **개선필요**: 응답이 어색함, 캐릭터 일부 이탈, 불필요하게 긴 응답
